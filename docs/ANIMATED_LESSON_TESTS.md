# 动画课件测试用例

> 基于第一章 5 个知识点（7a-1-01 ~ 7a-1-05）开发过程中发现的全部问题，固化为测试用例。
> 后续新生成动画课件时，必须逐条通过本用例。
> 最后更新：2026-10-21

---

## 一、启动与翻页

### TC-01 点击开始后从第一页播放
- **操作**：打开课件页面 → 点击"🎬 点击开始"
- **预期**：从场景 1 开始播放（不是场景 2 或其他）
- **回归原因**：点击开始后 document click handler 同时触发 `go(cur+1)` 导致跳页

### TC-02 点击开始后提示消失
- **操作**：点击"点击开始"
- **预期**："🎬 点击开始"提示立即消失，不残留
- **回归原因**：提示元素未被正确移除，在后续页面仍可见

### TC-03 场景内容不跨页泄露
- **操作**：从场景 1 翻到场景 2、3、4…（含含 SVG/动画的场景）
- **预期**：每个场景只显示自己的内容，其他场景内容完全不可见
- **机制要求**：`.scene { opacity:0; pointer-events:none }` + `.scene.active` 恢复（或 `display:none/block`，两者均可）；关键是**场景 div 必须配对闭合**，且标签书写正确
- **回归原因**：① `<div="scene">` 畸形标签使场景完全脱离隐藏样式控制；② 场景内 `</div>` 多余/缺失使内容溢出到场景容器外（常显在所有页面）

### TC-04 音频播完自动翻页
- **操作**：播放任意场景，等待音频结束
- **预期**：音频结束后 500ms 自动翻到下一场景
- **回归原因**：JS 补丁叠加导致 `audio.onended` 被覆盖或丢失

### TC-05 点击画面翻页
- **操作**：在任意场景点击空白区域
- **预期**：翻到下一场景（有 300ms 冷却，不会连翻）

### TC-06 键盘操作
- **操作**：按 `空格`（暂停/播放）、`→`（下一页）、`←`（上一页）
- **预期**：分别对应暂停/播放、翻页、回退

### TC-07 顶部圆点跳转
- **操作**：点击顶部进度圆点
- **预期**：跳转到对应场景并播放该场景音频

### TC-08 最后一个场景播完后停止
- **操作**：播放到最后一个场景
- **预期**：音频结束后不翻页，显示暂停状态

## 二、例题场景

### TC-09 题目和解答不同时出现
- **操作**：翻到例题场景
- **预期**：题目卡（黄色）先出现 → 语音读题到约 35% 时解答卡（绿色）淡入 → 75% 时点评卡（紫色）浮现
- **回归原因**：CSS animation delay 太短导致同时弹出

### TC-10 data-reveal-at 是独立 HTML 属性
- **操作**：检查解答卡的 HTML
- **预期**：`data-reveal-at="0.35"` 是独立属性（不在 style 属性内）
- **回归原因**：data-reveal-at 被错误插入 style 属性，浏览器无法识别

### TC-11 解答卡初始隐藏
- **操作**：翻到例题场景，音频刚播放时
- **预期**：解答卡不可见（opacity: 0），题目卡正常显示

### TC-12 解答卡随音频进度显示
- **操作**：例题场景音频播放中
- **预期**：音频进度约 35% 时解答卡从下往上淡入

### TC-13 例题场景有完整音频
- **操作**：检查例题场景的音频文件是否存在
- **预期**：`{pid}/{sceneIndex}.mp3` 文件存在且可播放
- **回归原因**：追加场景后 sceneAudio 数组未更新

## 三、方法提炼（脑图）

### TC-14 脑图连线完整显示
- **操作**：翻到方法提炼场景
- **预期**：中心节点到每个分支的连线全部可见，无缺失
- **回归原因**：stroke-dash 动画参数不匹配导致连线部分隐藏

### TC-15 脑图框内文字不溢出
- **操作**：检查每个分支卡片的文字
- **预期**：关键词（3~6 字）+ 简短说明（≤12 字）完全在框内，不折行不溢出
- **回归原因**：用整句话填充导致文字超出框宽

### TC-16 脑图使用关键词而非长句
- **操作**：检查脑图分支标题
- **预期**：标题是 3~6 字的关键短语（如"定基准"、"定正方向"），不是完整句子
- **回归原因**：直接从课件 body 提取导致放入长段落

### TC-17 脑图 SVG viewBox 足够大
- **操作**：检查脑图 SVG 的 viewBox
- **预期**：viewBox 宽 ≥ 860px，高度足够容纳所有分支，无裁剪

### TC-18 脑图动画不被 JS 破坏
- **操作**：翻到脑图场景，观察连线动画
- **预期**：连线用 opacity 淡入（mindmap-line），不被 JS 的 animation reset 破坏
- **回归原因**：JS 的 animation reset 会重置脑图连线的 CSS 动画

## 五、视觉与图形

### TC-20 图形位置正确（上下关系）
- **操作**：检查海拔/温度等对比图
- **预期**：珠峰在海平面之上，艾丁湖在海平面之下，上下关系正确
- **回归原因**：艾丁湖 SVG 与山峰在同一水平位置

### TC-21 图形形状合理
- **操作**：检查所有 SVG 图形
- **预期**：山峰用三角形，湖泊用椭圆，不使用不合适的形状
- **回归原因**：用倒立三角形表示湖泊

### TC-22 温度计旋转方向正确
- **操作**：检查温度计旋转动画
- **预期**：旋转后正温度（50°）在右侧（正方向右），负温度（−25°）在左侧
- **回归原因**：rotate(-90deg) 导致负数在右

### TC-23 数轴刻度位置正确
- **操作**：检查数轴上的点
- **预期**：0 在中心，正数在右，负数在左，间距均匀；分数/小数点位置准确
- **回归原因**：1/2 和 0.5 标在了错误位置（1.5 和 0.25）

### TC-24 对比色卡不折行
- **操作**：检查正/负数对比卡
- **预期**：绿色（正）和红色（负）卡片文字单行显示，不折行
- **回归原因**：卡片宽度不够导致文字折行

### TC-25 文字内容不跨场景残留
- **操作**：检查场景之间切换后是否有前一场景的文字残留
- **预期**：每个场景的文字只在本场景内显示
- **回归原因**：div 嵌套错误导致内容溢出到场景外

## 六、音频

### TC-26 音频数组与场景数匹配
- **操作**：检查 JS 中 `sceneAudio` 数组长度
- **预期**：与 `.scene` 元素数量一致
- **回归原因**：追加场景后数组未更新

### TC-27 所有音频文件存在
- **操作**：`ls {pid}/*.mp3 | wc -l` 对比场景数
- **预期**：音频文件数 = 场景数

### TC-28 播放/暂停按钮状态与音频一致
- **操作**：观察播放时和暂停时按钮
- **预期**：播放中显示 ⏸，暂停显示 ▶，与音频实际状态一致
- **回归原因**：Promise reject 导致状态不同步

### TC-29 进度条正常更新
- **操作**：音频播放中观察右下角进度条
- **预期**：进度条从 0% 增长到 100%

## 七、HTML 结构

### TC-30 每个 scene 的 div 开闭平衡
- **操作**：`python3 -c "..."` 检查每个 scene 内 `<div` 和 `</div>` 数量
- **预期**：opens == closes
- **回归原因**：追加场景时产生多余的 `</div>` 导致内容溢出

### TC-31 所有 scene 有 class="scene"
- **操作**：`grep -c 'class="scene"' *.html`
- **预期**：每个场景的 div 有正确的 class 属性
- **回归原因**：`<div="scene">`（缺少属性名）导致场景不受任何隐藏样式控制，常显并遮挡其他场景

### TC-32 SVG viewBox 不裁剪内容
- **操作**：检查所有 SVG 的 viewBox 尺寸
- **预期**：viewBox 大于所有元素的坐标范围

## 自动化检测（tools/check-animated-lessons.py）

以上用例中可机检的部分已固化为自动化脚本，**生成任何新课件后必须先跑它**：

```bash
python3 tools/check-animated-lessons.py              # 检测全部课件
python3 tools/check-animated-lessons.py 7a-1-06     # 检测指定知识点
python3 tools/check-animated-lessons.py --quiet     # 只列失败项（失败退出码 1，可接 CI）
```

### 机检规则与用例对应

| 规则 | 检查内容 | 对应用例 |
|---|---|---|
| S01 | `.scene` 有隐藏机制（opacity:0 或 display:none）+ pointer-events:none；`.scene.active` 恢复 | TC-03 |
| S02 | 无畸形标签（`<div="scene">`） | TC-31 |
| S03 | 每个场景 div 配对闭合；末场景闭合后无泄漏内容 | TC-03/TC-30 |
| S04 | document click 有 `if(cur<0)return` 守卫 | TC-01 |
| S05 | 开始提示有 remove() 移除逻辑 | TC-02 |
| S06 | `audio.onended` 自动翻页存在 | TC-04 |
| S07 | 播放按钮状态由音频事件驱动 | TC-08 相关 |
| E01 | 例题场景含 `data-reveal-at` 渐进元素 | TC-09 |
| E02 | `data-reveal-at` 是独立属性（不在 style 内） | TC-10 |
| E03 | reveal 阈值在 0~1 之间 | TC-09 |
| C01 | 场景类型齐全（例题 + 方法提炼 + 易错，且总数 ≥6） | TC-12 |
| C02 | 音频文件数 = 场景数，且均 >10KB 非空 | TC-27 |
| C03 | 讲解稿 JSON 条数 = 场景数 | — |
| C04 | 脑图每个分支都有动画连线 | TC-14 |
| C05 | 脑图连线/分支框坐标都在 viewBox 内（不裁剪） | TC-15/TC-32 |
| C06 | 脑图分支标题 ≤12 字（关键词而非长句） | TC-16 |

> 检测器自身经过反向验证：把 6 类历史 bug（畸形标签/中间场景多关/末场景泄漏/缺守卫/reveal 嵌 style/缺音频）注入副本，6/6 全部被检出。

### 无法机检、必须人工看的用例

TC-20（图形上下关系）、TC-21（形状合理）、TC-22（旋转方向）、TC-23（数轴刻度数学正确）、TC-24（不折行）——这些是**内容语义**层面的正确性，生成后需人工过一遍。

## 使用方法

### 新增课件时（必走流程）

1. 生成 HTML + 讲解稿 + 音频
2. `python3 tools/check-animated-lessons.py <知识点ID>` → 必须全部 PASS
3. 人工测试三个最关键用例：**TC-01**（从第一页播放）、**TC-09**（例题渐进展示）、**TC-14**（脑图连线完整）
4. 内容语义抽查：TC-20~TC-24（图形数学正确性）
5. 全部通过再交付

### 回归测试

改过模板/生成脚本后，对全部已交付课件重跑检测器：

```bash
python3 tools/check-animated-lessons.py
```
