# 课件动画化处理方案

> 从课件文本 → 动画 HTML → 讲解稿 → 语音配音的完整流水线规范。
> 样例：`app/public/demo/lesson-demo.html`（正数和负数的意义，4 场景）
> 最后更新：2026-10-21

---

## 一、流程总览

```
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  课件文本   │────→│  动画 HTML  │────→│  讲解稿     │────→│  语音配音   │────→│ ✅ 自动检测 │
│ (data/     │     │ (每知识点   │     │ (对准画面   │     │ (MiniMax   │     │ check-     │
│  lessons/) │     │  3~5 场景)  │     │  + 衔接词)  │     │  TTS)      │     │ animated-  │
└────────────┘     └────────────┘     └────────────┘     └────────────┘     │ lessons.py │
                                                                            └────────────┘
                                                          全部 PASS + 人工抽查图形数学正确性 → 交付
```

**核心原则**：每个知识点不是一页文字，而是 **3~5 个视觉场景**，用动画讲清一个概念。
**质量门禁**：每生成一个课件必须通过自动化检测（`docs/ANIMATED_LESSON_TESTS.md` 的 16 条机检规则），否则不予交付。

## 二、第一步：课件文本 → 动画 HTML

### 2.1 场景拆分规则

| 课件页类型 | 拆分方式 | 场景数 |
|---|---|---|
| 概念讲解（concept） | 情境引入 → 核心概念 → 图形演示 → 生活应用 | 3~4 场景 |
| 例题精讲（example） | 题目呈现 → 思考停顿 → 解答步骤 → 点评 | 3~4 场景 |
| 方法提炼（method） | 问题引入 → 方法步骤 → 示例演示 | 2~3 场景 |
| 易错提醒（pitfall） | 错误示范 → 正确做法 → 对比总结 | 2~3 场景 |
| 新思维拓展（book） | 背景故事 → 核心探究 → 结论 | 3 场景 |

### 2.2 HTML 模板结构

每个场景是一个 `<div class="scene">`，场景间通过 CSS `opacity` 切换：

```html
<div class="stage">                          <!-- 深色渐变全屏背景 -->
  <div class="scene" id="s1">...</div>      <!-- 场景 1 -->
  <div class="scene" id="s2">...</div>      <!-- 场景 2 -->
  <div class="scene" id="s3">...</div>      <!-- 场景 3 -->
  <div class="dots">...</div>               <!-- 顶部进度点 -->
  <div class="hint">...</div>               <!-- 底部操作提示 -->
</div>
```

### 2.3 视觉设计规范

| 元素 | 规格 |
|---|---|
| **背景** | 深色渐变（`#1a1a2e → #16213e → #0f3460`）+ 装饰粒子 |
| **卡片** | 半透明玻璃效果（`rgba(255,255,255,.1)` + `backdrop-filter: blur`） |
| **正数/负数** | 绿色（`#10b981`）/ 红色（`#f43f5e`），对比鲜明 |
| **关键概念** | 金色（`#f59e0b`）高亮卡片，带呼吸动画 |
| **文字** | 白色主文（`#fff`）+ 灰色辅助（`#94a3b8`），不折行 |
| **字号** | 标题 2.2rem / 卡片正文 1.2rem / 注释 0.9rem |

### 2.4 动画类型库

| 动画名 | CSS 类名 | 效果 | 适用场景 |
|---|---|---|---|
| 弹入 | `.bubble` + `pop-in` | scale(0)→scale(1) + 旋转回弹 | 对话气泡、选项卡片 |
| 上滑 | `.dir-card` + `slide-up` | translateY(40px)→0 + 淡入 | 方向牌、信息卡片 |
| 掉落 | `.nl-point` + `dot-drop` | translateY(-30px)→0 + 弹跳 | 数轴上的点、标记 |
| 浮动 | `.money-icon` + `bounce` | 上下弹跳循环 | 图标、装饰元素 |
| 脉冲 | `animate` SVG | r 值循环变化 | 关键点强调（0 = 分界线） |
| 淡入 | `fade-in` | opacity 0→1 + 轻微上移 | 文字说明、总结 |

### 2.5 SVG 图形规范

| 图形 | 说明 | 参数 |
|---|---|---|
| 数轴 | 横线 + 刻度 + 正负区色块 + 关键点 | viewBox 700×120，间距 100px |
| 温度计 | 竖条 + 填充色 + 标签 | 简化为卡片对比即可 |
| 网格 | 3×3 方格 | 用于幻方/矩阵 |
| 坐标系 | 两轴 + 网格 + 描点 | 用于平面直角坐标系 |

## 三、第二步：动画 HTML → 讲解稿

### 3.1 核心原则

讲解稿不是朗读课件文本，而是**对着画面讲课**。

### 3.2 写作规则

| 规则 | 正例 | 反例 |
|---|---|---|
| **指代画面** | "你看这条线""看左边绿色卡片" | "数轴上负数在左边"（不说"看"） |
| **衔接过渡** | "那怎么把方向写进数字里呢？" | （场景间直接跳，无衔接） |
| **老师口吻** | "来，先做个小测试""谁对？其实都对" | "下面我们学习正数和负数" |
| **停顿标记** | "穿什么？。有人抢答"（？。=停0.5s） | "穿什么？有人抢答"（不停顿） |
| **收尾行动** | "记住这个规则，做题就不会搞混了" | （无收尾，讲完就结束） |
| **不念数学符号** | "记作正 5" | "记作 +5"（TTS 会读成"加5"） |

### 3.3 场景衔接模板

| 位置 | 衔接语示例 |
|---|---|
| 场景1→2 | "那怎么办呢？。" / "那怎么把方向写进数字里呢？。" |
| 场景2→3 | "现在把这些数放到数轴上，看得更清楚。" |
| 场景3→4 | "最后看看正负数在生活中怎么用。" |
| 结尾 | "记住这个规则，以后做题就不会搞混了。" |

### 3.4 讲解稿长度参考

| 场景类型 | 目标时长 | 字数参考 |
|---|---|---|
| 情境引入 | 25~35 秒 | 100~150 字 |
| 概念讲解 | 20~30 秒 | 80~120 字 |
| 图形演示 | 15~25 秒 | 60~100 字 |
| 应用总结 | 25~35 秒 | 100~150 字 |

## 四、第三步：讲解稿 → 语音配音

### 4.1 当前配置

详见 `docs/VOICE_CONFIG.md`。

| 项 | 值 |
|---|---|
| 引擎 | MiniMax TTS（`speech-02-hd`） |
| 音色 | `male-qn-jingying`（精英男声） |
| 语速 | `1.15`（快节奏，干脆利落） |
| 音调 | `0`（原调） |
| 格式 | MP3, 32kHz, 128kbps |

### 4.2 停顿编码

在讲解稿中用 `？。` 和 `。。` 编码停顿（TTS 自动识别）：

| 编码 | 含义 | 停顿时长 |
|---|---|---|
| `？。` | 问句后停顿（等学生思考） | ~0.5s |
| `！。` | 感叹后停顿 | ~0.5s |
| `。。其实` | 揭示答案前停顿（思考感） | ~0.5s |
| `。。所以` | 推理前停顿 | ~0.5s |
| `。。我们来看` | 过渡语前停顿 | ~0.5s |

### 4.3 生成命令

```bash
# 单个知识点
cd app && node scripts/gen-lesson-audio.ts --point 7a-1-01

# 一章
node scripts/gen-lesson-audio.ts --chapter 7a-c1

# 全量（增量，未变化的跳过）
npm run gen:audio
```

## 五、第四步：音画同步（HTML 内嵌）

### 5.1 音频文件

```
app/public/demo/audio/
├── s1.mp3    ← 场景 1 的讲解
├── s2.mp3    ← 场景 2
├── s3.mp3
└── s4.mp3
```

### 5.2 JS 同步逻辑

```javascript
// 核心逻辑：音频播完 → 自动翻到下一场景
const audio = new Audio()
const sceneAudio = ['audio/s1.mp3', 'audio/s2.mp3', ...]

function go(n) {
  // 切换场景
  scenes[cur].classList.remove('active')
  scenes[n].classList.add('active')
  cur = n
  // 播放对应音频
  audio.src = sceneAudio[cur]
  audio.play()
}

audio.onended = () => {
  if (cur < scenes.length - 1) go(cur + 1)  // 自动翻页
}
```

### 5.3 用户控制

| 操作 | 效果 |
|---|---|
| 点击画面 | 翻到下一场景 |
| ← / → 键 | 前一场景 / 下一场景 |
| 空格键 | 暂停 / 恢复播放 |
| 顶部圆点 | 跳转到指定场景 |
| 右下角 ⏸/▶ | 播放控制 + 进度条 |

## 八、质量检查清单

### 自动化检测（强制，先于人工检查）

```bash
python3 tools/check-animated-lessons.py <知识点ID>   # 必须全部 PASS 才能交付
```

16 条机检规则（S/E/C 系列）覆盖第一章开发踩过的全部结构类坑，规则明细见 `docs/ANIMATED_LESSON_TESTS.md`。

### 人工检查（机检覆盖不到的内容语义）

- [ ] 图形数学正确：上下关系（珠峰在上/艾丁湖在下）、数轴刻度位置、旋转方向（正数在右）
- [ ] 图形形状合理（山峰三角、湖面椭圆，不用不合适的形状）
- [ ] 每个场景的文字在一行内完整显示（不折行）
- [ ] 正数用绿色、负数用红色、关键概念用金色
- [ ] 讲解词中有指代画面的语句（"你看""看这张卡片"）
- [ ] 场景之间有衔接过渡语
- [ ] 问句后有停顿（？。标记）
- [ ] 讲解词时长与场景动画时长匹配
- [ ] 最后一个场景有收尾总结
- [ ] 点击开始从第一页播放；音频播完后自动翻页
