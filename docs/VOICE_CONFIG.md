## 二、声音风格要求

### 2.1 整体定位

"学霸淡定讲题"——冷静、自信、可信赖，不急不躁但有分量。

### 2.2 具体要求

| 维度 | 要求 | 反例（避免） |
|---|---|---|
| **语气** | 有力、自信、从容 | 有气无力、拖沓、犹豫 |
| **节奏** | 清晰有停顿，给学生思考时间 | 连珠炮式一口气读完 |
| **情感** | 冷静克制、略带酷感 | 过于甜美/热情/做作 |
| **可信度** | 像懂的人给你讲，一切尽在掌握 | 像在念稿、不确定 |
| **AI 感** | 尽量自然，接近真人 | 明显的机器朗读感 |

### 2.3 已试过并淘汰的声音

| 声音 | 淘汰原因 |
|---|---|
| macOS Tingting | 拼接式合成，机械感强 |
| `female-chengshu`（成熟女声） | 太柔，缺乏力度 |
| `male-qn-qingse`（清涩青年男声） | 有气无力，节奏拖沓 |
| `male-qn-jingying`（精英男声） | AI 感强，不够自然 |
| `male-qn-badao`（藏书青年男声） | 不够有朝气 |
| `presenter_female`（女主播） | 播报腔，不像讲课 |
| `presenter_male`（男主播） | 同上 |
| `female-tianmei`（甜美女声） | 过于甜美，不适合数学 |

## 三、自然停顿规则

在 `app/src/lib/narration.ts` 的 `speakable()` 函数末尾实现。

### 3.1 原理

在句末标点后追加多余的 `。`（句号），TTS 引擎遇到连续句末标点会自然停顿约 0.5 秒，模拟老师提问后等待学生思考的节奏。

### 3.2 停顿触发点

| 场景 | 规则 | 效果 |
|---|---|---|
| **问句后** | `？` 后紧跟内容 → 变为 `？。` | 提问后停一拍，等学生想 |
| **感叹后** | `！` 后紧跟内容 → 变为 `！。` | 强调后停顿 |
| **过渡语前** | "我们来看" 前加 `。` | 转换话题前停顿 |
| **转折前** | "其实" 前加 `。` | 揭示答案前的思考感 |
| **因果前** | "所以" 前加 `。` | 推理前的停顿 |
| **提醒前** | "注意" 前加 `。` | 强调重要内容前停顿 |

### 3.3 代码位置

```typescript
// app/src/lib/narration.ts → speakable() 函数末尾
t = t
  .replace(/？(?=[^，。！？；\s])/g, '？。')
  .replace(/！(?=[^，。！？；\s])/g, '！。')
  .replace(/([。！？])我们来看/g, '$1。我们来看')
  .replace(/([。！？])其实/g, '$1。其实')
  .replace(/([。！？])所以/g, '$1。所以')
  .replace(/([。！？])注意/g, '$1。注意')
```

## 四、讲解词文本规范化

在 `speakable()` 函数中处理，确保数学内容可被 TTS 正确朗读。

### 4.1 符号转读法（核心规则）

| 原文 | 朗读为 | 说明 |
|---|---|---|
| `-3` | 负 3 | 前缀负号 |
| `+8` | 正 8 | 前缀正号 |
| `3 - 5` | 3 减 5 | 中缀减号 |
| `a + b` | a 加 b | 中缀加号 |
| `= -(5+3)` | 等于负（5加3） | 等号后带符号括号 |
| `2/3` | 3 分之 2 | 分数线 |
| `×` / `÷` | 乘 / 除以 | 乘除号 |
| `√16` | 根号 16 | 平方根 |
| `∛27` | 三次根号 27 | 立方根 |
| `80²` | 80 的平方 | 上标 |
| `℃` | 摄氏度 | 温度单位 |
| `0.5 m` | 0.5 米 | 长度单位 |
| `∠AOB` | 角 AOB | 角度 |
| `△ABC` | 三角形 ABC | 三角形 |
| `∥` / `⊥` | 平行于 / 垂直于 | 几何关系 |
| `>` / `<` / `≥` / `≤` | 大于 / 小于 / 大于等于 / 小于等于 | 不等号 |
| `→` | 然后 | 流程箭头 |
| `…` | 以此类推 | 省略号（数学中等差/等比） |
| `……` | 等等 | 省略号（文字叙述） |

### 4.2 括号处理

| 原文 | 朗读为 | 说明 |
|---|---|---|
| `(-1) + 2` | 负 1 加 2 | 纯数学括号去掉 |
| `（如 3、2、π）` | 停顿 | 中文括号变为停顿 |
| `(1)` | 第一 | 编号括号 |

### 4.3 数字保留

原文中的所有数字必须**原样保留**在朗读文本中，不得丢失或改动。生成脚本有程序校验。

## 五、生成管线

### 5.1 命令

```bash
cd app

# 全量（增量：未变化的段落自动跳过）
npm run gen:audio

# 只生成某一章
node scripts/gen-lesson-audio.ts --chapter 7a-c1

# 只生成某个知识点
node scripts/gen-lesson-audio.ts --point 7a-1-01
```

### 5.2 增量机制

- 每段讲解词计算 SHA1 哈希
- 与 manifest 中的历史哈希比对
- 相同 → 跳过；不同 → 重新生成
- 课件内容改动后重跑即可，只会重生成受影响的段落

### 5.3 输出结构

```
app/public/audio/
├── manifest.json                    ← 哈希 + 时长索引
└── lessons/
    ├── 7a-c1/
    │   ├── 7a-1-01-0-0.mp3         ← 第 1 个知识点、第 1 页、第 1 步
    │   ├── 7a-1-01-1-0.mp3
    │   ├── 7a-1-01-2-0.mp3         ← 例题：题目步
    │   ├── 7a-1-01-2-1.mp3         ← 例题：解答步
    │   └── ...
    └── ...
```

### 5.4 前端加载

```typescript
// app/src/lib/data.ts
export function lessonAudioUrl(chapterId, pointId, slideIdx, stepIdx): string {
  return `${AUDIO_BASE}/lessons/${chapterId}/${pointId}-${slideIdx}-${stepIdx}.mp3`
}
```

## 六、更换声音的步骤

1. 修改 `app/.env` 中的 `TTS_VOICE`（及 `TTS_SPEED` / `TTS_PITCH`）
2. 删除旧音频：`rm -rf app/public/audio/lessons/`
3. 重新生成：`cd app && node scripts/gen-lesson-audio.ts`
4. 前端无需改动（自动使用 `.mp3` 扩展名）

## 八、MiniMax API 技术细节

| 项 | 值 |
|---|---|
| 端点 | `POST https://api.minimax.chat/v1/t2a_v2` |
| 认证 | `Authorization: Bearer <API_KEY>` |
| 音频返回格式 | **hex 编码**（不是 base64！） |
| 解码方式 | `Buffer.from(data.data.audio, 'hex')` |
| 超时 | 120 秒（长文本可能较慢） |
| 并发 | 建议 ≤ 4（过高可能触发限流） |
| pitch 类型 | **整数**（-12 到 12，不能用小数） |
| speed 范围 | 0.5 到 2.0 |
